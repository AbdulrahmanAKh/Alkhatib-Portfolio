# Portfolio (Vite + React + Tailwind)

    npm install
    npm run dev      # http://localhost:5173
    npm run build    # outputs to dist/

Edit your content in `src/data.js`. Sections use hash routes (#about, #resume, #projects, #certificates, #contact).
Thumbnails: add `img: '/thumbs/x.png'` to any project or certificate (put files in `public/thumbs/`).
